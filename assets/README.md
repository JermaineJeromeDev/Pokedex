## 🌟 Beschreibung / Description

Interaktive **Pokédex Web-App**, erstellt während der **Developer Akademie** Weiterbildung als **Trainingsprojekt**.  
Die App zeigt Pokémon-Karten an, erlaubt Suche und bietet eine Overlay-Ansicht mit Tabs für **About**, **Base Stats** und **Moves**.

Interactive **Pokédex web application**, created as a **training project** during the **Developer Akademie** course.  
View Pokémon, search for them, and see detailed information in tabs for "About", "Base Stats", and "Moves".

---
## ⚡ Features

- Pokémon-Karten mit Name, Typen & Basiswerten
- Echtzeit-Suche
- Detaillierte Overlay-Ansicht:
  - About (Art, Größe, Gewicht, Fähigkeiten)
  - Base Stats (HP, Attack, Defense etc.)
  - Moves (erste 10 Attacken)
- Responsive Design (Desktop & Mobile)
- Lade-Overlay während Datenabfrage
- Burger-Menü für mobile Navigation
- Footer mit Impressum & Datenschutz

- Pokémon cards with name, types & basic stats
- Real-time search
- Detailed overlay view (About, Base Stats, Moves)
- Responsive design
- Loading overlay
- Burger menu
- Footer with legal links
